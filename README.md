## Agenda de Contatos 

Projeto desenvolvido em C# como uma aplicação de console para gerenciamento de contatos pessoais.

## Sobre o projeto

O projeto Agenda tem como objetivo permitir o cadastro e gerenciamento de contatos, armazenando informações como:

Nome
E-mail
Data de nascimento
Telefone
Tipo de telefone
Telefone principal

A aplicação foi desenvolvida utilizando conceitos de Programação Orientada a Objetos (POO) e listas (List<T>).

## Funcionalidades

O sistema possui as seguintes opções:

0. Sair
1. Adicionar contato
2. Pesquisar contato
3. Alterar contato
4. Remover contato
5. Listar contatos

## Tecnologias utilizadas
C#
.NET
Console Application
Programação Orientada a Objetos
Listas (List<T>)

## Classes
Data

Responsável pelo armazenamento da data de nascimento do contato.

Possui:

Dia
Mês
Ano
Formatação da data no padrão dd/mm/aaaa
Telefone

Representa um telefone cadastrado para o contato.

Possui:

Tipo
Número
Indicação se é o telefone principal
Contato

Armazena os dados pessoais do contato.

Possui:

Nome
E-mail
Data de nascimento
Lista de telefones
Cálculo da idade
Busca pelo telefone principal
Contatos

Responsável pelo gerenciamento da agenda.

Permite:

Adicionar contatos
Pesquisar contatos
Alterar contatos
Remover contatos
Listar contatos
